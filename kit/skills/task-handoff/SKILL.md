# Task Handoff

Use the existing active task entry; do not replace another task. On pause record scope/non-goals, relevant files/contracts, current Git state, accepted decisions, commands/results, failed hypotheses, risks, pending approvals and the exact next step. On resume read it and reconcile current files before trusting stale evidence. On completion report DONE, DONE_WITH_CONCERNS or BLOCKED with scoped files, criterion-to-evidence mapping, browser/API gaps and next action. Update wiki/graph only for durable changed knowledge. Delete only this completed task file and its active pointer; retain unfinished publication or blocked work. Never place secrets or full tool logs into context. Do not claim checks were executed from a prior summary without identifying that evidence as prior.
