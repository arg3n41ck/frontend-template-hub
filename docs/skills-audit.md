## Distribution and ownership

Canonical files live in `.ai/skills`; three small portable adapter directories point to them. Task/risk manifest `.ai/workflows.json` is checked against real files. Graphify/wiki are required knowledge workflows; large references are lazy. Side effects, browser QA, parallel ownership and release authorization have focused suite-owned workflows.

Third-party source catalog contains no root LICENSE file in the supplied checkout. Existing license files were not changed and no redistribution assurance is made. Optional graphifyy runtime has its own upstream package terms; those do not automatically license modified skill assets from another repository. No new license was chosen on the owner's behalf.

Public registry pins still describe the existing releases, not these uncommitted additions. Update refs/commits/full skill inventories together only after an authorized source release. See ai-first-design.md, community-release.md and knowledge-skills.md.
